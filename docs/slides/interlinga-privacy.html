Privacy is decided at session creation — before a single word is spoken

Interlinga.ai respects privacy

Every commitment below is enforced in code, not promised in a policy — including a feature turning itself off rather than quietly reaching the cloud anyway.

Audio isn’t recorded by default Live audio is never stored unless a facilitator explicitly opts in for the session. i18n.ts — privacyNote
Retention set up front 1 / 7 / 30 days, chosen at session creation — an hourly job deletes every cascading row (transcript, chat, insights) past deadline, then sweeps any now-orphaned user record. retention/cleanup/route.ts
LOCAL_ONLY mode A session can be locked to self-hosted local-inference only — speech-to-text and translation never leave the building. session-contracts.ts · caption-agent.ts
The understanding layer honors it too In a LOCAL_ONLY session, the Claude-based insight layer simply doesn’t run — disabled, not silently rerouted to the cloud. insights.ts:53
Anonymous means anonymous An anonymous learner's real name is redacted on the server before the message ever reaches the page — not just hidden by the UI, where View Source or DevTools would still expose it. message-visibility.ts
Sensitive signals stay scoped Per-learner confusion levels and analytics are gated behind facilitator access; private messages are filtered out of the query itself for anyone but sender/recipient. learner-confusion.ts · message-visibility.ts
The difference that matters: most privacy settings are a promise about what a feature won’t do. This one is enforced by turning the feature off when the setting says to — the code has no other path.
